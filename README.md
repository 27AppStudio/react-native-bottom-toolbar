# react-native-bottom-toolbar

Native bottom toolbar for React Native: UIKit's toolbar on iOS (Liquid Glass on iOS 26) and a Material 3 floating toolbar on Android.

## Installation


```sh
npm install react-native-bottom-toolbar
```


## Usage


```js
import { multiply } from 'react-native-bottom-toolbar';

// ...

const result = multiply(3, 7);
```
